# 量潮联盟第二大脑

量潮联盟第二大脑是联盟主体的组织知识系统：开源工作档案（`data/`）与知识库（`docs/`）作为单一事实源，产品应用（`apps/`）承载业务与治理，实验室（`examples/`）承载探索。

## 定位

联盟是量潮的治理机构之一，与公司（`defaults/quanttide-tech`）、实训基地（`defaults/quanttide-academy`）并列的法人主体。本仓承载联盟主体自己的档案：它管什么、依据什么、与社区和公司如何划界。

## 目录

| 目录 | 内容 |
|:--|:--|
| `data/context/` | 语境档案（想法、未澄清的线索） |
| `data/journal/` | 日志 |
| `data/profile/` | 档案 |
| `docs/` | 知识库 |
| `apps/` | 联盟相关的产品应用 |

目录随接入的子仓库增长，未接入前不预留空目录。
